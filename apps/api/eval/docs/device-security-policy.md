# Device and Account Security Policy

This policy applies to every device used to access company systems, whether company-owned or personal.

## Laptop encryption

Full-disk encryption is mandatory on all laptops: FileVault on macOS and BitLocker on Windows. Devices are checked automatically and a laptop without encryption is cut off from company systems until it is fixed. Never disable the screen lock; it must engage after five minutes of inactivity.

## Lost or stolen devices

If a laptop or phone is lost or stolen, report it to the security team within 1 hour of noticing, day or night, using the emergency hotline. The security team will remotely wipe the device and revoke its sessions. Do not wait to see whether the device turns up, and do not try to track it yourself.

## Passwords and second factors

Use the company password manager for every work account and never reuse passwords. Passwords must be at least 14 characters long. Multi-factor authentication is required for all systems that support it, and administrators must use hardware security keys rather than phone-based codes.

## Public Wi-Fi

Never handle company data on an untrusted network such as a cafe or hotel without the VPN connected. Connect to AcmeVPN first, then open your work applications. If the VPN cannot connect, use your phone as a hotspot instead of joining the open network.

## Software installation

Install only software from the approved list in the IT portal. If you need something else, file a request and the IT team will assess it, usually within two working days. Browser extensions count as software and are covered by the same rule.

## Phishing

Report suspicious emails with the Report Phish button in your mail client instead of forwarding them. The security team runs simulated phishing campaigns every quarter. Clicking a simulated link is not punished, but the follow-up training is mandatory.

## Personal devices

Personal phones may be used to read work email only after enrolling in mobile device management, which lets the company wipe work data without touching personal content. Personal laptops are not allowed to access production systems.
